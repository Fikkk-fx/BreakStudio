## 🔒 23. THE SHOT-BOUNDARY DIALOGUE ENCLOSURE & VISUAL PROP ALIGNMENT CODEX (V20.5 SSOT)

To eliminate temporal dialogue bleed and missing prop contradictions across cuts:

### 1. ⏱️ STRICT DIALOGUE ENCLOSURE WITHIN SHOT BOUNDARIES:
* Spoken dialogue windows **MUST NEVER CROSS OR OVERLAP AN EDITORIAL HARD CUT**:
  * If Shot 1 runs from `0.0s to [Cut 1]`, dialogue MUST conclude at `<= [Cut 1] - 0.3s` (allowing a ≥0.2s reaction buffer before the cut).
  * If Shot 2 runs from `[Cut 1] to [Cut 2]`, dialogue MUST conclude at `<= [Cut 2] - 0.4s` (allowing a ≥0.2s reaction buffer before the next cut).
  * **RULE:** `Dialogue End Time <= Cut Timestamp - 0.2s`.

### 2. 🪛 STRICT VISUAL PROP ALIGNMENT WITH SPOKEN DIALOGUE:
* If a character verbally references any physical object, that object **MUST BE EXPLICITLY DESCRIBED IN THE PROSE & SPATIAL SET** before the dialogue occurs:
  * **Action:** If shouting *"Grab the fire extinguisher!"* — the extinguisher must already exist in the scene description.
  * **Romance:** If saying *"Put down the letter"* — the letter must be established in the character's hand.
  * **Sci-Fi:** If ordering *"Activate the shield!"* — the shield console must be part of the spatial set.
  * **RULE:** 0% ghost props that exist only in speech but never in visual scene architecture.

### 3. 🔄 CONTINUOUS LINEAR-TO-ROTATIONAL PHYSICAL TRANSLATION:
* When characters manipulate heavy or complex objects, describe both the linear movement AND the final rotational/positional placement:
  * **Action:** *"Character drags the heavy furniture into position, then pivots it sharply to wedge the exit."*
  * **Crime:** *"Detective slides the evidence box across the table, then rotates it to face the suspect."*
  * **Sci-Fi:** *"Engineer pushes the coolant rod forward, then twists it 90° into its locked cradle."*

### 4. 💡 COHERENT AUDIO ROOM HUM WITH ESTABLISHED LIGHTING:
* If primary illumination is a tungsten pendant, Block 5 `[SPATIAL ACOUSTICS]` must describe:
  * *"Subtle electrical hum from the aging ceiling fixture"* (avoid calling it 'fluorescent' if no fluorescent lights exist).

### 5. 🚫 ABSOLUTE PURGE OF DRY PHYSICS METRICS:
* Strictly ban dry numbers like `2.4 m/s`, `9.8 m/s² gravity`, `static equilibrium`.
* Replace with: *"heavy physical force ➔ high-friction sliding ➔ wedging ➔ violent frame recoil"*.
