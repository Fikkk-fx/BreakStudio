# 🛡️ 15. ROOF INTENT & INTAKE CENSUS CODEX (PRIMARY ANTI-AI SHIELD)

## §AT — INTENT IS THE ROOF (THE DUAL-SHIELD DOCTRINE)
Before writing any camera, lighting, or technical craft, establish the **PRIMARY NARRATIVE POINT**: What should the audience feel, understand, and remember from this visual sequence?

Every directorial element MUST serve this intent. Anything merely decorative or unmotivated is instantly cut.

```text
┌────────────────────────────────────────────────────────────────────────────────────────┐
│                               THE DUAL ANTI-AI SHIELDS                                 │
├────────────────────────────────────────────────────────────────────────────────────────┤
│ 🛡️ BIG SHIELD (Primary): Story Intent, Stakes & Hook (§AT, §AT-HOOK, §AT-CARE)        │
│   → Without narrative intent, a technically flawless video still feels like AI filler! │
│ 🛡️ SMALL SHIELD (Secondary): Micro-Textures, Skin Pores, FACS Somatics, SSS (§R, §BD) │
│   → Polishes the visual surface once the emotional engine is locked.                   │
└────────────────────────────────────────────────────────────────────────────────────────┘
```

## §AT-INTAKE — USER ENTITY CENSUS (TURN 1 INTAKE MANDATE)
Before generating any screenplays, asset sheets, or prompt blocks, the agent MUST extract EVERY single entity from the user's literal prompt:

1. **LITERAL & EXPLICIT SCANNING:**
   - People / Named Characters (including elders, children, background groups)
   - Animals / Creatures
   - Vehicles / Transports
   - Rooms / Architectural Environments
   - Named Tactical Props / Tools
   - Screens / Gadgets / Photos / Documents
   - On-Screen Text / Logos / Brand Identity
   - Future Damage States (e.g. "then he gets soaked", "his jacket rips")

2. **READ-BACK PROTOCOL:**
   The agent MUST read the exact counts back to the user out loud for confirmation:
   > *"Sensus Entitas: 2 Tokoh Utama (Silas, Maya), 1 Kerumunan Latar (4 pejalan kaki), 1 Ruang (Gedung Terbengkalai), 2 Properti Taktis (Kerambit, Datapad) — Apakah kuota ini sudah sesuai?"*

3. **0% SILENT ASSUMPTION:** If the user specifies a vague count (*"some people"*, *"a squad"*), the agent MUST immediately ask for an exact number before proceeding.

4. **INTAKE CHECKSUM LOCK (§D-INTAKE-MATCH):**
   The locked intake list serves as the root master count. All subsequent screenplay breakdowns, asset sheets, and video prompt blocks MUST match this count. If a prompt drops an intake entity, it triggers **Bug #104** and generation is halted.

## §AT-HOOK — EARNING THE FIRST 2 SECONDS (THE 3 OPENING FAMILIES)
AI video viewers decide whether to keep watching within 2.0 seconds. Every scene/clip must open on ONE of the 3 proven hook families:

```text
┌─────────────────────────────────────────────────────────────────────────────────────────┐
│                              THE 3 OPENING HOOK FAMILIES                                │
├─────────────────────────────────────────────────────────────────────────────────────────┤
│ 1. 🏃 MOTION HOOK: Opening in mid-movement or kinetic momentum (door kicking open,      │
│    water splashing off a boot, rapid magazine insertion, falling glass shattering).    │
│ 2. 👁️ FACE / EMOTION HOOK: Opening on a tight portrait mid-reaction (sudden pupil      │
│    dilation, jaw clench, breath shudder, sharp gaze shift).                             │
│ 3. ❓ TENSION / QUESTION HOOK: Opening on an image posing an immediate enigma (a locked │
│    safe clicking open, a blinking red LED counter at 00:04, blood on a keycard).        │
└─────────────────────────────────────────────────────────────────────────────────────────┘
```
- **STRICTLY BANNED:** 0% slow, empty, unmotivated establishing panning shots as the scene opener (#1).

---

## §AT-CARE — PLANTING NARRATIVE STAKES
Within the first 5 seconds of the clip, establish a tangible emotional stake:
- A desperate want or goal
- An imminent physical/psychological threat
- A fragile human bond
- An urgent countdown

Beauty without stakes is instantly forgettable (#2).
