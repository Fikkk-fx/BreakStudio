# 🛑 17. ZERO-DEFECT BUG BANK & LIVE TRIAGE CODEX (123 KNOWN FAILURES)

## §J & §K — RULES OF THE MASTER BUG BANK
1. **ONE BUG = ONE ROW:** Every observed flaw traces directly to a single root section.
2. **NUMBERS OVER ADJECTIVES:** Every fix enforces measurable units (cm, %, count, Kelvin, seconds).
3. **K-5 HONEST DIRECTORIAL TRIAGE:**
   - **BOOKKEEPING BUGS (100% Fixable in Rules):** State ordering, missing entities, 180° flips, duplicate tags, miscalculated words. These are 100% prevented by strict prompt math and ledger checksums.
   - **RENDER CEILINGS (Model Physical Limits):** Broken anatomy, impossible joint flexibility, complex compound grapples. These are mitigated by simplifying verbs (`§B SPECIFIC-VERB`), splitting into separate clips (`§E ONE-ACTION-PER-CLIP`), and re-generating at Turn 6 / T5 using Ground Truth inspection (`§D-GROUNDTRUTH`).

## §M-TRIAGE — LIVE PRODUCTION ERROR TRIAGE MATRIX
When reviewing actual generated clips at Turn 6 / T5:
1. **If it is a Bookkeeping Bug (#110, #111, #104, #109):** Fix the master ledger and prompt code immediately before continuing.
2. **If it is a Render Ceiling Bug (Complex anatomy, triple grapple):** Simplify the kinetic verb into single actions (`§E`), adjust camera framing to wider coverage, and re-generate the single clip.
